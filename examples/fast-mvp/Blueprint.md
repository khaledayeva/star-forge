# Blueprint.md

Status: approved example

## Product Summary

A small habit tracker MVP for web/mobile-style UI demonstration.

## Product Goal

Let a user create, complete, and review daily habits quickly.

## User-Facing Behavior

- Add a habit.
- Mark today's habit complete.
- See a simple streak count.

## Tech Stack

React or Expo-style frontend with smoke tests.

## UX Quality Bar

Primary flow must work on desktop and mobile widths, include empty state, and be visually verified.

## Acceptance Criteria

- User can add a habit.
- User can complete a habit.
- Streak updates visibly.
- Smoke test covers primary flow.

## Definition Of Done

Implementation, smoke test, visual verification, review, ledger entry, Plan.md update, and recommended next step are complete.
