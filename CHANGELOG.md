# Changelog

All notable Star Forge changes are documented here.

## 0.4.0 - 2026-07-26

### Added

- One-call lifecycle from adaptive interview and original design direction through
  Blueprint lock, Plan v2, repository foundation, build, review, delivery, and
  strict completion.
- Data-driven capability routing across official plugins, MCP servers, native
  Codex tools, Computer Use, and explicit fallbacks.
- Direct Mobbin App OAuth integration for Blueprint design research without stored
  repository credentials or a bundled MCP configuration.
- Source-bound Foundation and Delivery contracts for local work, private GitHub
  repositories, previews, production, packages, and platform targets.
- Evidence envelope v2 with compatible v0.3 evidence readers and platform proof
  routes for web, iOS, macOS, Expo, CLI, security, and GitHub.
- Risk-derived review roles with Fast MVP floors, a four-agent cap, and dedicated
  UI originality, accessibility, security, privacy, and reliability lenses.
- Scoped post-completion change packets that preserve historical Plans and repeat
  only affected verification, review, and delivery gates.
- Read-only installation doctor, deterministic quality budgets, safe opt-in global
  learnings, end-to-end fixture projects, self-dogfood, and release-candidate
  smoke matrices.

### Changed

- Star Forge is modularized behind the existing CLI with authoritative runtime
  Python held below the 18,000-line release budget.
- Generated project agent profiles and public workflow documentation now reflect
  the complete v0.4 lifecycle and capability router.
- Optional hooks and local agent ledgers remain diagnostic. Completion continues
  to rely on source-bound coordinator evidence and Git facts.

### Compatibility

- Existing v0.3 Plans, amendment rows, reviews, completion proofs, and evidence
  remain readable.
- Plan v2 migration creates a separate reviewable draft and never rewrites the
  historical Plan automatically.
- Missing legacy Delivery contracts default to source-only rather than inventing a
  deployment target.
